# Project Charter — Verifiable Evaluation Criteria for Generative Reward Models

## 研究问题

让评价标准本身具备可验证性：GRM 不仅执行评价标准，还能生成、检查并验证标准本身。

核心困难不在于"生成更多标准"或"写更长的 CoT"，而在于**标准缺陷（criterion defect）与执行缺陷（executor defect）在现有验证信号中不可分离**。所有现有方法的过滤信号形如 `keep(C, ψ) = 1[J(C,ψ,y,e) = l]`，只观测到两者的复合误差。

## 目标

1. 为 criterion 质量建立可操作、可测量的定义（Validity / Coverage / Discrimination / Consistency / Evidence-Validity）。
2. 提出至少 3 个机制不同的验证框架，并说明其独立于生成器的机制来源。
3. 建立"标准写得合理"与"标准确实有效"的可区分实验设计。
4. 验证 criterion 侧代理指标是否预测下游 Policy 收益。

## 不在范围内

- 以增加 CoT 长度为核心贡献的工作。
- 单纯的 rubric 生成器改进（该方向 2026 年已饱和）。
- 视频生成质量评价（本项目面向评价标准的可验证性，不绑定单一模态）。

## 关键约束

| 约束 | 内容 |
|---|---|
| 独立性 | 验证器不得与生成器共享同一错误；独立性只能来自结构、信息或自指三种来源之一 |
| 负面结果 | E3 若否定核心假设，属于可接受且有价值的结果 |
| 报告纪律 | 静态准确率与 Policy 收益必须分开报告；不得用 GRM 自身奖励证明 Policy 变强 |
| 证据边界 | 未经 GPT 核实的检索条目不得作为论文证据 |

## 主要风险

1. **撞车**：SVR、MM-VeriRubric、CARO、MRRG 已占据大部分叙事。
2. **前提失效**：若标准质量对结论无实质影响（E0 显示装饰性标准与生成标准统计等价），全部方案作废。
3. **本体不可扩展**：Coverage 方案需要外部维度清单，工程成本高。
4. **奖励退化**：不变性目标可能奖励空泛标准，必须与判别性联合优化。
