这反而使研究问题更锋利。本文件的核心论断是：

> 2026 年所有验证 criterion 的方法，其验证信号最终都追溯到**"这组标准能否复现一个已知标签"**，而反例/负样本又是由**同一模型族**构造的。因此它们可以测出"标准看起来合理且与标签一致"，但**在原理上无法测出"标准是否覆盖了生成器从未想到的维度"**，也无法把 criterion 缺陷与 executor 缺陷分开。

这个论断是 §2.3 的命题、§3.2 的三个开放问题的共同来源，也是三个方案的设计靶心。

## 1. 问题重述

### 1.1 任务书的五条属性不是并列的

任务书列出 Validity / Coverage / Discrimination / Consistency / Evidence-Validity 五条。它们不是同一层的属性，混在一起设计会得到一个没有重点的系统。按"需要一个什么样的外部参照系"重新分层：

| 属性 | 需要的外部参照 | 可否无参照自检 |
|---|---|---|
| Discrimination | 偏好标签或可比样本对 | ✗（需要排序真值） |
| Consistency | **无**（变换族自洽） | ✓ |
| Evidence-Validity | 证据本体（视频、文档、执行轨迹） | 部分（有本体即可） |
| Validity | 人类裁决 | ✗ |
| Coverage | **维度清单**（外部本体） | ✗（这是最硬的一个） |

这张表的直接结论：**Consistency 是唯一可以在完全没有 Ground Truth 的情况下被严格检验的属性。** 这一条决定了 §5 方案二的设计，也解释了为什么它是最便宜的切入点。

### 1.2 Coverage 与 Yield 是两个不同的量，现有文献把它们混用了

`Auto-Rubric`〔[S]，arXiv 2510.17314，式 (9)〕把 Coverage 定义为"该标准在多大比例的测试样本上给出非 tie 的判别信号"：

$$\text{Coverage}(r_j)=\frac{1}{|D|}\sum_i \mathbb{I}\big[\text{eval}_{r_j}(x_i,y_i^+,y_i^-)\neq \text{tie}\big]$$

这个量测的是**适用频次**，不是**维度完整性**。一条标准可以在 100% 样本上给出非 tie（Coverage=1），同时整个标准集完全漏掉"拒答是否恰当"这个维度。前者我称之为 **Yield**，后者才是 Coverage。命名混淆不是小事：它让"覆盖不足"这个被 `RRD` 明确列为四大失效模式之一的问题，至今没有一个可计算的度量。

本文件统一使用：

- **Yield**：给定标准集，产生非 tie 判定的样本比例（= 上式的量）。
- **Coverage**：相对一个**外部维度清单** $D(x)$ 的覆盖率（定义见 §2.4 D2）。

### 1.3 三个概念必须分开，且分开后是一个嵌套结构

任务书要求区分 Logical Consistency（LC）、Evidence Grounding（EG）、Judgment Validity（JV）。严格写出来是：

$$\text{JV} \;\Longleftrightarrow\; \underbrace{\text{LC}}_{\text{判定由标准+观察推得}} \;\wedge\; \underbrace{\text{EG}}_{\text{观察为真}} \;\wedge\; \underbrace{\text{CV}}_{\text{标准本身恰当且完整}}$$

三者相互独立：

- **LC 成立而 EG 不成立**：幻觉证据 + 严密推理。`R1-Reward` 的 Consistency Reward 只能测 LC，其 Referee 检查的是"推理与答案是否自洽"，明确不检查推理是否有视觉依据（见文献综述 P14 局限栏）。
- **EG 成立而 CV 不成立**：真实观察 + 错误标准。例如视频里确实发生了 A 事件，但标准只奖励"描述详尽"，于是详尽但错误的回答胜出。
- **三者都成立而 JV 不成立**：聚合环节出错，如权重错配、tie 处理错误。

**CV（Criterion Validity）不是上述三者的第四项，它是 JV 的一个必要条件。** 现有工作的验证几乎全部落在 LC 和"标签一致"上，CV 没有独立的测量位置。这是本研究要补的那个位置。

## 2. 形式化：把"标准有效性"变成可测量的量

### 2.1 记号

| 记号 | 含义 |
|---|---|
| $x$ | 任务输入（视频+问题 / Prompt / 代码题） |
| $e$ | 证据本体（视频帧与时间轴、检索文档、执行轨迹） |
| $y$ | 候选回答 |
| $C=\{c_1,\dots,c_K\}$ | 标准集（Principles / Rubric） |
| $J(C,y,e)$ | 执行器输出的判定（偏好或分数） |
| $l$ | Gold 标签 |
| $\phi$ | 标准生成器 |
| $\psi$ | 标准执行器 |
| $D(x)$ | **外部维度清单**（不依赖生成器） |

### 2.2 现有验证信号的定义

把 4 篇 rubric 产出的论文的过滤机制统一写成一个式子。它们全部形如：

$$\text{keep}(C,\psi)\;=\;\mathbb{1}\big[\,J(C,\psi,y,e)=l\,\big]$$

- `OpenRubrics`：组级 `Acc_i ≥ τ`（τ=0.5）且当前 pair 预测正确〔已核对 PDF §4.2, Eqs.(1)–(3)〕。
- `DeepSeek-GRM`：Eq.10 逐点 argmax 与真值一致 → Rejective FT；GRPO 奖励同式〔已核对 PDF Eq.(10)(11)〕。
- `Mix-GRM`：RLVR 奖励 = verdict 与标签一致；SFT 阶段**明确放弃**一致性过滤〔已核对 PDF App.B.3, p.14〕。
- `MM-VeriRubric`：受控错误维度 + 表面改写不变性检查〔[S] EMNLP 2026, Eq.(21)–(23)〕——这是唯一不完全依赖标签的，但负样本由同一 pipeline 构造。

### 2.3 命题：现有信号不可分解（本文件的核心论断）

**命题.** 设 criterion 缺陷为 $\delta_C$、executor 缺陷为 $\delta_\psi$。式 (1) 的观测值只依赖复合误差 $\delta_C \oplus \delta_\psi$，因而**任何**从 $\text{keep}(C,\psi)$ 出发对 $C$ 质量的估计，在 $\delta_\psi$ 未被单独测量或固定时都是有偏的。

**论证（非严格证明，三行）.**
$\text{keep}$ 是 $(C,\psi)$ 的联合函数。取任意 $\delta_C>0$ 且存在 $\delta_\psi$ 使其补偿，则 $\text{keep}=1$。反之取 $\delta_C=0$ 且 $\delta_\psi$ 使判定翻转，则 $\text{keep}=0$。两种情形下 $\text{keep}$ 给出与 $\delta_C$ 相反的读数。故 $\text{keep}$ 不是 $\delta_C$ 的充分统计量。∎

**三个直接推论，每一个都对应一类现有方法的已知可疑现象：**

1. **假阴性**：标准正确但执行器误用 → 好标准被丢弃。`DeepSeek-GRM` Table 1 的 "self-gen 75.9/55.6 vs filtered 77.8/57.5" 说明过滤确实带来收益，但同时说明**被过滤掉的那部分里含有多少好标准是未知的**。
2. **假阳性**：标准错误但整体产出正确标签 → 坏标准被保留并强化。这正是 `R1-Reward` 观察到并试图用乘性门控缓解的问题：错误的答案"仍可能因一致性分量获得高奖励"〔已核对 PDF §4.3, p.7〕。
3. **错误抵消**：两者都错、方向相反 → 被保留，且训练信号会同时强化两个错误。

**证据支持。** `JEV vs. LLMs as Rubric Judges`〔[S]〕报告"校准的决策模型与 LLM rubric 判官在**同一批标准上**出错"，即 $\delta_C$ 与 $\delta_\psi$ 高度相关；`Beyond the Illusion of Consensus`〔[S]〕把这种虚假共识追溯到**共享的 rubric 结构**；`Great Models Think Alike`〔[S] 2025〕用 chance-adjusted 相似度证明判官偏好与自己相似的模型。三条独立证据都指向同一结论：$\delta_C \oplus \delta_\psi$ 的耦合不是假设，是可观测现象。

> **这一节是全文的立论基础。** 如果 §2.3 被推翻（即存在某个已知信号确实分解了 $\delta_C$ 与 $\delta_\psi$），则 §5 三个方案的必要性大幅下降。Research Audit 阶段应优先攻击这一命题。

### 2.4 五条属性的可操作定义

**D1 Validity（标准正确性）**
$c$ 对 $x$ 有效，当且仅当对任意 $y$，"$c(y)$ 成立"这一判断与外部裁决（人类专家或程序化 Oracle）一致。仅可在**抽样并裁决**的子集上测量，报告一致率与 Cohen's κ。
注意：`VideoPhy-2` 的规则级标注者一致性只有 70–80%〔已核对 PDF fn.9, p.8〕，这是这个量现实的可达上限，不可忽略。

**D2 Coverage（覆盖率）**
给定外部维度清单 $D(x)$：
$$\text{Cov}(C;x)=\frac{\big|\{\,d\in D(x):\exists c\in C,\; c\ \text{operationalizes}\ d\,\}\big|}{|D(x)|}$$
必须是 **ontology-relative**（相对本体）。分母来自外部，不由 $\phi$ 产生。**这是文献缺口的关键**：若 $D(x)$ 也由模型生成，Coverage 退化为自指。

**D3 Discrimination（区分能力）**
在**困难层**（near-tie 样本）上，$c$ 诱导的排序与真排序的 AUC，条件于非 tie。必须分层报告 easy / hard。理由：`SVR`〔[S] EMNLP 2026〕的核心论点是"self-generated rubric 描述'好回答'，而有效标准必须区分'接近的候选'"——在 easy 层上测不出这个差别。

**D4 Consistency（稳定性）**
对一族**语义保持变换** $\mathcal{T}$（标准改写、顺序置换、拆分/合并、表面改写）：
$$\text{Cons}(C)=\mathbb{E}_{t\sim\mathcal{T}}\Big[1-\mathrm{TV}\big(J(C),\,J(t(C))\big)\Big]$$
在 criterion 级与 set 级分别测量。**不需要 Ground Truth。**

**D5 Evidence-Validity（证据有效性）**
两部分，必须分开报告：

- **Grounding rate**：critique 中承重断言被 $e$ 蕴含的比例，由**独立机制**（检索、执行、时序定位、跨族模型）核验。
- **Abstention correctness**：证据不足时判定是否拒答，而非强行断言。这是 `VideoPhy-2` 的 "Cannot Be Determined" 类别〔已核对 PDF §3.1, p.5〕给我的关键启发——**验证器必须被允许说"无法判定"，否则会被迫编造。**

### 2.5 "装饰性"与"有效性"的操作主义区分

这一条直接回应任务书 §4「设计能区分'标准写得合理'与'标准确实有效'的实验」。

- **单条标准装饰**：$J(C)$ 与 $J(C\setminus\{c\})$ 在预设定等价界 $\delta$ 内**统计等价**。
- **标准集装饰**：$J(C)$ 与 $J(C_{\text{null}})$ 等价，其中 $C_{\text{null}}$ 是一组通用空泛标准。

**方法学要点：必须用等价性检验（TOST），不能用零假设检验。**
"$p>0.05$ 所以无差异" 是错误推理。要主张"这条标准没用"是一个**正面主张**，必须做等价性检验并预先声明 $\delta$。这直接解释了 §3.3 中那个令人不安的数字为什么不能直接采信。

**结论：不要在"设计更好的标准生成器"或"给标准打分"这两个方向上正面竞争。**

### 3.2 仍然开放的三件事

#### 开放问题 O1：Coverage 没有外部参照系，所有"盲点发现"都是自指的

`MRRG` 明确命名了 "dimensional blind spots"，但它的解法是用 5 个**模型内部角色**换取视角多样性。`RRD` 用模型递归分解。`DR-Tulu` 用 rollout 探盲点。三者共享同一个结构性限制：

> 生成器无法提出一个它从未表征过的维度。

多角色之所以有效，是因为角色是**人类先验**注入的（User / Educator / Linguist 是人为选定的）。它没有解决"如何**测量**还剩多少没覆盖"，只是增加了命中概率。而 `Auto-Rubric` 用 "Coverage" 命名了一个实为 Yield 的量。

**⇒ 真正的开放问题：能否建立**不依赖生成器**的维度清单，使 Coverage 成为可计算的量？**

#### 开放问题 O2：所有 criterion 质量代理指标是否预测下游 Policy 收益，无人验证

`Scaling Laws for Generative Reward Models` 已证明：静态评估准确率更高的 Thinking Judge，在 8 组匹配设置中的 7 组给出的 Policy Elo **更低**（平均峰值差 +126；`Answer-Only − Thinking` 峰值差在 4B/14B 配置为 +269 [128, 488]）〔已核对 PDF Table 3, p.10〕。

整个 2026 rubric 优化工业正在优化一批**从未被验证过**的代理指标：SVR 的 margin、Auto-Rubric 的 Precision/Contribution、GenRubric 的判别性奖励、PReMISE 的 effective dimensionality。**没有任何一项工作报告过"提高该指标 → Policy 变强"。**

**⇒ 真正的开放问题：criterion 质量的哪个度量对下游 Policy 收益有预测力？** 这是 `Scaling Laws` 的直接类比，成本低、结论硬、无人做。

#### 开放问题 O3：标准质量中"应答条件化泄漏"未被分解

`OpenRubrics` 从 (chosen, rejected) 对生成标准；`MM-VeriRubric` 从参考回答 $y^+$ 生成标准。标准在**看到答案之后**产生。`SVR` 明确把"在观察任何候选回答前固定标准"作为卖点，说明社区已意识到问题——但**没有人量化泄漏有多大**。

若"高质量标准"的大部分收益来自标准在事实上编码了标签，则整个方向的解释是错的。

**⇒ 真正的开放问题：把标准质量分解为"先验质量"与"泄漏"，各自贡献多少？**

### 3.3 一个必须正视的张力：两个数字互相矛盾

| 证据 | 数字 | 蕴含 |
|---|---|---|
| `SVR`〔[S]〕 | 自生成标准与人类标准在 RubricBench 上差 **24.1 分**，SVR 缩到 0.3 | 标准质量是**一阶**因素 |
| `Mix-GRM`〔已核对 PDF Fig.4b, p.8〕 | 随机选标准 69.9 / 70.6，一致性 Top-10 71.8 / 72.7 | 标准选择只值 **1–2 分**，随机已超过 vanilla |

两个结论不可能同时为真，除非它们测的不是同一件事。我的判断（待验证）：

- `SVR` 测的是**困难样本上到人类标准的距离**；`Mix-GRM` 测的是**同一模型自生成标准内部的选择**。前者问"自生成标准有多差"，后者问"在已经差的标准池里挑更好的有没有用"。
- 二者可以同时成立：**标准池整体质量低（SVR），池内选择收益小（Mix-GRM）**。这恰好支持 §3.2 O2——真正的杠杆在池的质量而非选择，而"池的质量"恰恰没有任何代理指标能可靠测量。

**这个张力必须在实验 E0 中被显式解决**（§6.1），否则后续所有工作建立在一个未核实的量级假设上。

## 4. 威胁模型：生成器与验证器共享错误

任务书明确要求每个方案回答"如何避免生成器和验证器共享同一错误"。先给出通用威胁模型，方案设计再逐条对号。

| ID | 威胁 | 机制 | 已有证据 |
|---|---|---|---|
| **T1** | 知识盲点相关 | 生成器不知道某个事实，验证器也不知道 | `JEV vs LLM judges` 同批出错〔[S]〕 |
| **T2** | 共享 rubric 结构 → 虚假共识 | 双方用同一套标准框架，错误同构 | `Beyond the Illusion of Consensus`〔[S]〕 |
| **T3** | 自偏好 / 谄媚 | 验证器看到生成器的产出后倾向认可 | `Great Models Think Alike`〔[S]〕 |
| **T4** | 验证器被利用 | 生成器学会写出"骗过验证器"的标准 | `RcRL` 报告的 reward hacking〔[S]〕 |
| **T5** | 分布同源 | 同一训练语料 → 同一盲区 | `Scaling Laws` 的 Gold 亦是学习模型〔已核对 PDF §5〕 |

**关键设计原则（本文件的核心方法论主张）：**

> 独立性不能靠"换一个更强的模型"获得。换模型只降低 T5 的参数相关性，不改变 T1–T4。**真正的独立性只有三种来源：**

| 独立性类型 | 含义 | 阻断的威胁 | 代价 |
|---|---|---|---|
| **结构独立** | 验证信号由**非模型**机制产生（执行、检索、程序变异、本体） | T1–T5 全部 | 覆盖范围受限 |
| **信息独立** | 结构性限制信息流（应答盲、标签盲） | T3, T4 | 需要重新设计训练流程 |
| **自指独立** | 用**蜕变关系**检验，不需要任何外部真值 | T1–T3 | 只能测稳定性，不能测正确性 |

三个方案分别锚定这三种独立性。这是它们机制互不相同的根本原因，也是它们可以互补而非竞争的原因。

## 5. 三个方案

每个方案统一回答任务书要求的四问：**验证对象 / 验证信号来源 / 开放式标准如何处理 / 如何避免共享错误**，再加**失败模式**与**最小可证伪实验**。

---

### 方案一：Ontology-Seeded Coverage（OSC）—— 外部维度本体驱动的覆盖率

#### 核心假设

> H1：标准集的**本体相对覆盖率**（D2），而非其 Yield 或判别性，是预测下游 Policy 收益的主要 criterion 侧因素。

#### 验证对象

**V3 层：标准集整体的维度完整性**，相对一个外部清单 $D(x)$。不验证单条标准的文本质量，也不验证执行过程。

#### 验证信号来源

$D(x)$ 来自**三个非生成器来源**的并集：

1. **人工裁决的失效分类学**（per task family）。例如 TV2T：事件存在性、计数、时序、因果、空间关系、属性、证据充分性、恰当拒答。这张表由人类写，不由 $\phi$ 产。
2. **程序化变异算子**。一个变异算子**蕴含**一个维度：能"删除被引用的证据跨度"就说明"引用支持"是一个维度；能"交换两个事件的时间戳"就说明"时序"是一个维度。算子集是可枚举的、可执行的。
3. **已发表失效分类学**。`RRD` 的四类失效模式、`VideoPhy-2` 的物理规则体系〔已核对 PDF〕——这些是文献沉淀的人类先验，可复用为 $D(x)$ 的种子。

然后计算 $\text{Cov}(C;x)$，并对**未被覆盖的槽位**做定向诱导（把缺口显式喂回 $\phi$）。这是与 `MRRG` 的关键区别：`MRRG` 增加采样视角，OSC **先测缺口再补**。

#### 开放式标准如何处理

这是本方案最难的一环，必须诚实：

- 本体**永远不完整**。因此只报告 **ontology-relative coverage**，绝不声称绝对覆盖。文档中必须写 "coverage with respect to $D_v$ (version v)"，并公开 $D$ 的版本。
- 不可操作化的标准（无法编译为可检验谓词）单独计数，记为 **unformalizable rate**——这个数字本身是发现，不是失败。
- 开放式主观维度（文风、有用性）放入 $D$ 的 "human-adjudicated only" 分区，不参与自动测量，只参与 E1 的人工审计。

#### 如何避免共享错误

**结构独立。** $D(x)$ 不经过任何 LLM 生成，变异算子是可执行代码。$\phi$ 无法通过"写出骗过 $D$ 的标准"获益，因为 $D$ 不评判标准，只枚举维度。

残留风险：$D$ 本身不完备（人类也没想到的维度）。这是**有界且可声明**的，优于自指方案的无界风险。缓解：E1 中报告"人工审计新增维度数 / 初始 $D$ 规模"，量化本体迭代的边际收益。

#### 失败模式

- **F1.1 本体工程不可扩展**：为每个任务族手工建 $D$ 成本过高 → 退化为一个 Benchmark，而非方法。
- **F1.2 覆盖率与任何结果都不相关** → H1 死。这是最可能也最有价值的失败。
- **F1.3 覆盖率被"刷"**：生成器学会为每个 $D$ 槽位写一条敷衍标准，覆盖率 100% 但质量为零。**必须用 D1（Validity）交叉验证**，不能单看覆盖率。

#### 最小可证伪实验（E1）

在 1 个任务族（建议 TV2T，与项目主线一致）、300 个样本上：

1. 构建 $D_v$（人工 8–12 维度 + 程序变异算子 5–8 个）。
2. 对 4 种标准集测 coverage：人工标准 / 强模型生成 / 弱模型生成 / 空泛标准。
3. 测每个标准集在 hard 层的 D3 与在人工裁决子集上的 D1。

**否定条件（任一即否）：**

- coverage 在四种标准集间**无可区分差异**（说明 $D$ 无信息量）；
- coverage 与 hard 层判别性 Spearman ρ 的 95% CI 跨 0；
- unformalizable rate > 70%（说明外部本体与真实标准空间几乎不相交，方法失去适用面）。

**支持条件：** coverage 与 hard 层 D3 显著正相关，且人工标准 ≫ 生成标准 ≫ 空泛，方向与 `SVR` 的 24.1 分差距一致。

### 方案二：Metamorphic Criterion Contracts（MCC）—— 蜕变关系下的标准不变性

#### 核心假设

> H2：大量 criterion 缺陷表现为**非不变性**（改写即翻转、顺序敏感、越界响应），而这一类缺陷可以在**完全没有 Ground Truth** 的条件下被检出并作为训练信号。
>
> 更强形式：H2′：以不变性为训练目标的标准集，其 hard 层判别性与跨样本稳定性同时提升，且提升**不是**来自与标签的更多接触。

#### 验证对象

**V2 层：标准作为从 (证据, 回答) 到判定的**函数**。** 不验证标准文本，验证它的变换行为。这是与 `MM-VeriRubric` 的核心区别：后者验证"标准集能否识别注入的错误维度"，MCC 验证"标准集在语义保持变换下是否不变、在语义改变变换下是否按预期改变"。

#### 验证信号来源

一族**蜕变关系（Metamorphic Relations）**。这是软件测试中"无 Oracle 测试"的标准技术，据本轮检索**尚未被用于 criterion 验证**——这是本方案最实质的新意。

| MR | 变换 | 期望 | 检出什么 |
|---|---|---|---|
| **MR1** | 标准改写（语义保持） | $\Delta J \approx 0$ | 措辞依赖 / 空泛 |
| **MR2** | 标准顺序置换 | $\Delta J \approx 0$ | 位置偏差、标准干扰 |
| **MR3** | 一条标准拆成两条 / 两条合并 | $\Delta J \approx 0$ | 粒度伪影、聚合权重脆弱 |
| **MR4** | 沿 $d_i$ 加大违规剂量 | 单调不增 | 剂量无响应 → 标准未被真正执行 |
| **MR5** | 沿 $d_i$ 变异回答 | 仅 $c_i$ 判定变化（**离对角 ≈ 0**） | **语义错配**：标准说 A，实际响应 B |
| **MR6** | 回答表面改写（内容保持） | $\Delta J \approx 0$ | 表面特征偏置（长度、格式） |
| **MR7** | 删除 $c_i$ | 仅在 $c_i$ 适用样本上判定变化 | 局部性：标准是否真的有承重作用 |

**MR5 的离对角质量是本方案的独立贡献。** 定义一个标准集的**错配矩阵** $M_{ij}=\mathbb{E}[\Delta J \mid \text{变异 } d_j]$，理想情况下 $M$ 近似对角。离对角质量高意味着标准集"对错误敏感但归因错误"——`CARO` 优化的是设计期的维度可分性，MCC 测的是**运行期的实际归因**，两者不同。

**MR7 提供逐条标准的因果贡献，且带局部性约束**，比 `Auto-Rubric` 的 Contribution（全局删除后精度下降）更严格：后者无法区分"该标准重要"与"该标准与其他标准冗余"。

#### 开放式标准如何处理

蜕变关系只要求**变换族与期望方向**，不要求知道正确答案。对开放式标准：

- MR1/MR2/MR3 对任何标准都适用（纯形式变换）。
- MR4/MR5 需要沿某个维度构造变异 → 只对可操作化标准适用，报告 **probeable rate**。
- MR6 对任何回答都适用。

因此开放式标准不是被排除，而是**被降级到形式不变性检验**。这是本方案覆盖面最广的原因。

#### 如何避免共享错误

**自指独立。** 蜕变测试不需要任何外部真值，也不需要第二个模型来当裁判。这对 T1（知识盲点）和 T3（自偏好）是**结构性免疫**——不询问任何人"这条标准好不好"。

**必须声明的局限（诚实边界）：** 蜕变测试检出的是**不稳定与非特异性**，不是**不正确性**。一条错误但在所有变换下都稳定且特异的标准会通过 MCC。因此 MCC 是**必要非充分**条件。它与方案一互补：OSC 测"缺不缺"，MCC 测"稳不稳"，两者都不测"对不对"，D1 只能靠人工裁决补。

#### 失败模式

- **F2.1 不变性太容易满足**：空泛标准天然满足全部 MR（它永远输出同一个判定）。**这是最危险的失败模式**——必须与 D3（判别性）联合优化，否则 MCC 会奖励退化。这是设计上的硬约束：$L = L_{\text{MR}} - \lambda L_{\text{D3}}$，$\lambda$ 不可为 0。
- **F2.2 probeable rate 过低**：真实标准大多不可构造变异。
- **F2.3 变换本身无效**：改写实际上改变了语义。缓解：改写对的语义等价性由独立模型 + 人工子集抽检双重确认。

#### 最小可证伪实验（E2）

固定执行器 $\psi$（如 Qwen3-8B），在 2 个任务族（文本 + 多模态）上，500 个样本 × 5 条标准：

1. 测量基线标准集的 MR1–MR7 通过率与 probeable rate。
2. 两个训练臂：(a) 仅 D3 目标；(b) D3 + MR 不变性惩罚。
3. 在**留出**的困难集上测 D3，在变换集上测 D4，并测 D1（人工子集）。

**否定条件（任一即否）：**

- 臂 (b) 的 D4 提升在 D3 上**无代价也无收益**（说明不变性与判别性正交，MCC 只是一个诊断工具，不能改进系统）；
- 臂 (b) 的 D3 显著下降（说明 F2.1 成真，不变性目标与判别性冲突，MCC 作为训练目标不成立）；
- probeable rate < 30%（说明只能做形式变换，工程价值有限）。

**支持条件：** 臂 (b) 在 D3 上不劣于 (a) 且 D4 显著提升。这是最强的支持形式——**免费获得稳定性**。

### 方案三：Leakage-Decomposed Criterion Induction（LDCI）—— 信息预算约束下的标准质量分解

#### 核心假设

> H3：现有"标准质量"收益可分解为**先验质量**（标准在未见答案时就具备的判别力）与**泄漏**（标准编码了它所见到的标签信息）。在 held-out pair 上，泄漏项很大。

#### 验证对象

**V1 层：标准的**生成条件**本身。** 不验证产出，验证"在什么信息预算下产出"。这是三个方案中唯一直接攻击 **Validity 的来源** 而非其表现的。

#### 验证信号来源

三档信息预算，逐档放宽：

| 条件 | $\phi$ 可见 | 对应现有工作 |
|---|---|---|
| **I0** | 仅 $(x, e)$ | 无（最严格，等价于"先固定标准"） |
| **I1** | $(x, e, y)$ | 部分 `MM-VeriRubric`（见 $y^+$） |
| **I2** | $(x, e, y^+, y^-, l)$ | `OpenRubrics` |

**关键测量设计——"同 Prompt 跨 Pair"分解：**
取同一 prompt 的 $N$ 个不同 pair，用 pair 1 诱导标准，在 pair 2..$N$ 上评测。

$$\underbrace{\text{Acc}(C_{\text{I2}})-\text{Acc}(C_{\text{I0}})}_{\text{总收益}}\;=\;\underbrace{\big[\text{Acc}_{\text{pair}\neq1}-\text{Acc}_{\text{pair}=1}\text{ 的差}\big]}_{\text{泄漏}}+\underbrace{\text{先验质量}}_{\text{剩余}}$$

预期：若标准主要编码标签，$C_{\text{I2}}$ 在 pair 1 上极好、在 pair 2..$N$ 上回落到 $C_{\text{I0}}$ 水平。

#### 开放式标准如何处理

信息预算限制对开放式与封闭式标准**同等适用**，因为它约束的是输入，不是输出形式。开放式标准在 I0 下仍可生成（从 prompt + 证据），只是无法针对具体候选做差分化——这正是"先验质量"的定义。

#### 如何避免共享错误

**信息独立。** 不依赖任何裁判的可靠性，只结构性限制信息流。T3（自偏好）与 T4（验证器被利用）被**设计消除**：I0 条件下没有答案可谄媚。

#### 失败模式

- **F3.1 泄漏可忽略** → H3 死。这会是**对整个子领域有利的负面结果**（说明现有方法测的是真东西），仍然可发表，但本方案自身失去价值。
- **F3.2 I0 标准质量太差** → 工程上不可用，只能作为诊断。
- **F3.3 同 Prompt 多 Pair 样本难构造**（视频任务尤其：同一问题通常只有一个视频）。

#### 最小可证伪实验（E3）

在文本偏好数据上（每个 prompt 有 ≥5 个回答，可构造 ≥4 个 pair）× 200 个 prompt：

1. 三档预算各生成标准，测 pair 1 与 pair 2..N 上的判别性。
2. 计算泄漏占比。

**否定条件：** $\text{Acc}_{\text{pair}\neq1}(C_{\text{I2}})-\text{Acc}_{\text{pair}\neq1}(C_{\text{I0}}) > 0.7\times$ 总收益 → 泄漏 < 30%，H3 被否定，方案三降级为对照实验。

**支持条件：** 泄漏占比 > 50%。此时本方案产生一个**领域级发现**：现有 rubric 生成方法的高分有相当部分是记忆。

## 6. 实验设计总纲

任务书要求"能区分'标准写得合理'与'标准确实有效'"的实验，并至少覆盖：标准正确性、覆盖率、区分能力、跨样本稳定性、RM 判定准确率、下游 Policy 收益。分三层组织。

### 6.1 E0 — 质量阶梯与张力调和（**必须先做**）

这是所有方案的共同前提，也解决 §3.3 的矛盾。

**设计：** 固定执行器，替换标准集，五档梯度：

| 档 | 标准集 | 作用 |
|---|---|---|
| L4 | 人类专家标准 | 上界（RubricBench 意义上的 oracle） |
| L3 | 强模型生成（GPT/Claude 级） | 现实上界 |
| L2 | 目标模型自生成 | 本研究对象 |
| L1 | 空泛标准（"回答是好的""内容准确"） | **装饰性对照** |
| L0 | 无标准（直接判） | 下界 |

**关键：分层 easy / hard 报告**，并用 TOST 做 L2 vs L1 的等价性检验（§2.5）。

**判据：** 若 L2 与 L1 在 hard 层统计等价，则"标准生成"这个范式在 hard 层的价值被证伪——所有方案必须转向"标准质量"而非"标准存在"。若 L2 ≫ L1，则 §3.2 的框架成立，SVR 的 24.1 分差距被独立复现。

### 6.2 E1–E4 — 三个方案的证伪实验 + 代理指标有效性研究

E1 (OSC)、E2 (MCC)、E3 (LDCI) 见 §5。

**E4 — 代理指标 → Policy 收益的有效性研究（O2，最高性价比）**

取 E1–E3 产生的约 20–30 个标准集变体，对每一个测量全部四个 criterion 侧代理指标（coverage、Yield、hard-AUC、Cons ∥ 泄漏占比），然后在同一 RL 配置下各跑一次短程 online training，测独立评估的 Policy 增益。

**产出：** 一张"代理指标 × Policy 增益"的相关矩阵。这直接补上 `Scaling Laws` 在 rubric 层面的类比空白。无论结果正负都是硬结论。

### 6.3 E5 — 对抗与金丝雀

向标准集注入 $m$ 条**已知错误**的标准（与 $D$ 冲突、与证据冲突、内部矛盾）。测量各方案的检出率。

**判据：** 检出率必须显著高于随机（二项检验）。若某方案的检出率接近随机，说明它不测量 Validity，只测量稳定性。

这一项直接回应任务书"如何避免生成器和验证器共享同一错误"——**金丝雀检出率就是共享错误的定量度量**。

### 6.4 指标与任务书六项要求的对应

| 任务书要求 | 操作指标 | 定义位置 |
|---|---|---|
| 标准正确性 | D1：人工裁决一致率 + κ | §2.4 |
| 覆盖率 | D2：ontology-relative coverage（配 unformalizable rate） | §2.4 |
| 区分能力 | D3：hard 层 AUC（非 tie，条件化） | §2.4 |
| 跨样本稳定性 | D4：$\mathcal{T}$ 变换下的 TV 距离 | §2.4 |
| RM 判定准确率 | 静态 Acc + Gold 一致性（**不可单独作为结论**） | §6.3 |
| 下游 Policy 收益 | 独立评估器 + 独立 benchmark；同时报告 reward hacking 率 | §6.2 |

**三条硬性报告纪律（源自文献综述 P4 与 `Scaling Laws`）：**

1. 静态准确率与 Policy 收益**必须分开报告**，不得用前者代替后者。
2. 不得用 GRM 自身的奖励分数证明 Policy 变强。
3. 所有实验必须区分 COMPLETE / PARTIAL / FAILED / BLOCKED。

## 7. 比较与候选排序

### 7.1 比较表

| 维度 | 方案一 OSC | 方案二 MCC | 方案三 LDCI |
|---|---|---|---|
| **验证对象（V 层）** | V3 标准集维度完整性 | V2 标准作为函数 | V1 生成条件 / 信息预算 |
| **验证信号来源** | 外部维度本体 + 程序变异算子 | 蜕变关系（无 Oracle） | 信息流结构约束 |
| **独立性类型** | 结构独立 | 自指独立 | 信息独立 |
| **是否需 Ground Truth** | 需 $D(x)$，不需标签 | **完全不需要** | 不需（只需 pair 结构） |
| **开放式标准处理** | 降级为 "human-only" 分区 + 报告 unformalizable | 降级为形式变换 MR1/2/3/6 | 同等适用（约束输入） |
| **主要覆盖原始属性** | Coverage, Validity | Consistency, Discrimination(特异), Evidence | Validity 的来源 |
| **与 2026 工作重叠** | 中（MRRG/RRD/DR-Tulu 同为覆盖，但参照系不同） | **高**（MM-VeriRubric MR4–MR6、CARO 可分性） | 低（SVR 提到但未量化） |
| **工程成本** | 高（本体构建） | 中 | 低 |
| **可证伪性** | 中（否定条件偏软） | **高**（三个干净否定条件） | **最高**（单一数字判据） |
| **最可能的产出** | Benchmark + 度量框架 | 训练目标 + 诊断工具 | **负面/审计发现** |
| **投稿撞车风险** | 中高 | **高** | 低 |

### 7.2 初步排序（非裁决）

**1st — 方案二 MCC。**
理由：唯一提供**无 Oracle 检验**的方案，因而对 §4 的 T1/T3 结构性免疫；覆盖 Consistency，是五条属性中 2026 年文献最少服务的一条；成本最低；否定条件最干净。风险是与 `MM-VeriRubric` 和 `CARO` 重叠——**必须把新意精确落在"运行期错配矩阵 MR5 + 局部必要性 MR7"上**，而不是"受控负样本验证"这个已被占领的表述。写作时必须显式对比这两篇。

**2nd — 方案一 OSC。**
理由：攻击的是最硬的概念空洞（Coverage 无外部参照），且提出 Yield/Coverage 的术语区分本身有领域价值。风险是容易被评为 "just a benchmark"，且本体构建成本高。若 Human 判断团队有本体工程资源，可上调至 1st。

**3rd — 方案三 LDCI。**
理由：作为**方法**最弱（本质是控制实验），但作为**审计**价值最高——它可能推翻整个子领域的前提。适合作为 E4 的一部分执行，而不是独立主线。

### 7.3 推荐组合

不建议只做一个。建议结构：

```
E0 (质量阶梯, 必做, 2周)
  └─ E3 (泄漏分解, 低成本, 4周)  ← 先做，因为它可能改变一切
       └─ E2 (MCC, 主线, 8周)
            └─ E1 (OSC, 并行, 10周)
                 └─ E4 (代理指标 × Policy, 12周)
```

E3 排在前面的理由是它成本最低而否决力最强：如果泄漏占比 > 50%，则 E1/E2 的"标准质量"测量全部被污染，必须先换到 I0 条件重做。**先做否决力最强的实验，是这里唯一正确的排序原则。**

### 7.4 什么会改变这个排序

- Human 决定主线是视频 TV2T：则方案一权重上升（视频的维度本体比文本更可枚举：事件、时序、空间、物理），方案三下降（同 prompt 多 pair 难构造）。
- Human 要求 6 个月内出顶会论文：则只做 E0 + E4，放弃三个方案的方法贡献，改为"评估有效性研究"。这是**可行的降级路径**，且 E4 单独就够一篇。
- E0 显示 L2 ≈ L1：全部方案作废，转向"标准为何无用"的机制研究。

## 8. 风险与待决事项

### 8.1 主要风险

| ID | 风险 | 严重度 | 缓解 |

### 9.4 建议 GPT 优先补检的方向

1. **criterion 质量的"预测效度"**：是否存在任何工作把 rubric 指标与下游 Policy 收益关联（O2 是否真空白）。
2. **metamorphic testing × LLM evaluation**：确认方案二的机制确无先例。

4. **信息泄漏 / 捷径学习在 reward modeling 中**：为方案三找理论支撑（如 shortcut learning、label leakage 文献）。
